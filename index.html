About me

I'm a Computer Science engineer who works where machine learning meets real products. I don't stop at the model or the interface: I design the data layer, train and evaluate the model, build the React front end, and ship it in Docker containers on AWS.

I start with the user's problem, build for maintainability, and measure success by whether a decision changes or time is saved. My proudest result is the Student Performance Predictor, which lets lecturers spot struggling students early enough to help them.
